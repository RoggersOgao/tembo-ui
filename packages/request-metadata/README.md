# @repo/request-metadata

Advanced request metadata extraction package for Node.js applications. Extract comprehensive request information including IP details, user agent, geolocation, security headers, and more.

## Features

- **IP Detection**: Advanced IP extraction with proxy detection
- **User Agent Parsing**: Detailed browser/OS/device information
- **Geolocation**: IP-based geolocation using GeoIP
- **Security Analysis**: TLS, headers, and threat detection
- **Performance Metrics**: Connection type and network info
- **Fingerprinting**: Client fingerprint generation
- **Analytics**: UTM, referral, and session tracking
- **TypeScript**: Fully typed interfaces

## Installation

```bash
pnpm add @repo/request-metadata
